Welcome to Python

Libraries

Let's learn some Python

1. Functions

  • print( )
    • shows content
  • del( )
    • (any data) - deletes some object forever [var, itr, num, etc...]
  • input( )
    • lets the user type something in
  • type( )
    • shows the object's type
  • [ ]
    • brackets create a list [x, y, z, ...] (vector)
    • also are used to call some part of an element
  • len( )
    • counts an object's lenght and returns it in a numeric value
  • range(n1, nn)
    • counts from 'n1' to 'nn' sequencially (numbers)
    • (n1, nn, z) - 'z' defines an increment value (1 by 1, 2 by 2, ...)
    • (n1, nn, -1) - counts backwards

2. Methods

  • . format( )
    • inserts the content inside it into the { } position
  • var[n]
    • calls an element's position
  • . isnumeric( ) / . isalpha( ) / . isalnum( ) / etc...
    • returns a boolean value depending on the object's type question
  • . max ( ) / . min ( )
    • returns the biggest or the smallest value from an iterable
String
  • . count( )
    • ('x') - counts how many times a character appears in the str
    • ('x', n1, n2) - counts with slicing
  • . find( )
    • ('xyz') - indicates the position value of a segment of text
    • returns -1 [minus one] if doesn't find anything
    • . rfind( ) starts the process from the RIGHT side
  • [var]. replace( )
    • ('x', 'y') - replaces 'x' str for 'y' str in [var]
  • . upper( )
    • turns all to UPPERCASE
  • . lower( )
    • turns all to lowercase
  • . capitalize( )
    • turns only the first word to Capitalized
  • . title( )
    • turns every single word to Capitalized
  • . strip( )
    • removes all the useless spaces in a string
    • . rstrip( ) removes the spaces on the right
    • . lstrip( ) removes the spaces on the left
  • . split( )
    • splits the str in all its spaces, dividing its words individualy
    • basically creates a list with every word inside it
    • you can print a word using its list numeric value 'x[n]'
    • with another value, you print only some character of it 'x[n][m]'
  • 'x'. join( )
    • (var) - puts an 'x' separator between each word and join them together again

3. Data Types

  • int( )
    • changes the object into an int type
  • float( )
    • changes the object into a float type
  • str( )
    • changes the object into a string type

4. Operators

  • + | - | * | /
    • sums, subtracts, times, divides
  • +=
    • incrementation
  • var1 = var2 = n
    • multi equal
  • 'a' in 'x'
    • returns True if 'a' is in 'x'
    • 'aBç' - can check many diferent values (doesn't need space)
    • 'x' in 'a' - the opposite comparation can also be possible if the second element is a container with the same type as the first one

5. Keywords

  • import
    • used to add some library in your Python environment
  • from [library] import [item]
    • add an especific element from some library

6. Structures

  • if elif else :
    • used in conditional structures
  • for var in [object] :
    • used in loop structures
    • range(n1, nn) - counts from 'n1' to 'nn' and keeps all the values into 'var'
    • var1, var2 in enumerate(itr) - calls the objects' positions and their values into each 'var' respectively in each loop

7. Iterables

  • var = itr1 + itr2
    • 'var' joins all the values in both the iterables
  • sorted(itr)
    • organizes the content in ascending order
  • enumerate(itr)
    • defines a numeric counter to each object in an iterable, making them a tuple of position and value respectively
  • len(itr)
    • returns the iterable's lenght
  • . count( )
    • (obj) - counts how many times an object appears in the iterable
  • . index( )
    • (obj) - calls the object's position
    • (obj, n) - calls the object's position starting from the 'n' position
Tuples
  • They are immutable!
  • tuple( )
    • creates an empty tuple
    • tuple(obj) - defines a tuple in an object
Lists
  • list( )
    • creates an empty list
    • list(obj) - defines a list in an object
    • (range(nx, ny)) - turns the range values in a list
  • . append( )
    • adds an object into the list
  • . insert( )
    • (n, 'obj') - adds an object into the 'n' position within the list
  • . pop( )
    • deletes the last object in the list
    • (n) - deletes the object in the 'n' position in the list
  • . remove( )
    • (obj) - deletes the mentioned object in the list
  • . clear( )
    • clears all the content in the list
  • . sort( )
    • sorts the list in ascending order
    • (reverse = True) - sorts the list in descending order
Dictionaries
  • dict( )
    • creates an empty dictionary
  • . keys( )
    • calls the object's keys
  • . values( )
    • calls the object's values
  • . items( )
    • calls both the object's keys and values
  • . copy( )
    • used to copy the list's content to some object
