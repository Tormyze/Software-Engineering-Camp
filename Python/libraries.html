Python's Libraries

* from [library] import [method], you just need the [method( )] syntax.

- math

  • built-in
  • library used to manipulate mathematic resources

  • math.[method]
    • ceil( )
    rounds the float number up
    floor( )
    rounds the float number down
    trunc( )
    roughly cuts all the numbers after the . in a float value
    pow( )
    makes exponenciations **
    sqrt( )
    makes square roots **(1/2)
    factorial( )
    makes factorial calculations !
    hypot(x, y)
    calculates the hypotenuse
    sin( )
    calculates the sine of a value
    cos( )
    calculates the cosine of a value
    tan( )
    calculates the tangent of a value
    radians( )
    toggles a value between angle or radian

- random

  • built-in
  • library that chooses a random value

  • random.[method]
    • random( )
    ( ) - chooses a number between 0 and 1
    randint( )
    (x, y) - chooses a number between any two int numbers
    choice( )
    chooses a value from a list
    shuffle( )
    shuffles the values in a list, and return None

- time

  • built-in
  • library that manipulates time aspects

  • time.[method]
    • sleep( )
    (n) - makes the program wait n seconds and, then, continues

- datetime

  • built-in
  • library that manipulates date

  • datetime.[method].[sub-method].[inner-method]
    • date.
    manipulates date arguments
    time.
    manipulates time arguments

    today( )
    calls today's argument
    now( )
    calls now's argument

    .year - calls the current year
    .month - calls the current month
    .day - calls the current day
    .hour - calls the current hour
    .minute - calls the current minute
    .second - calls the current second
